BPMN Modeller
Приложение предназначено  для загрузки и симуляции бизнес-процессов, представленных в нотации BPMN 2.0. Программа принимает готовую BPMN-модель в формате XML, анализирует её структуру и визуализирует прохождение токенов по элементам процесса. Проект позволяет наблюдать, как изменяется состояние процесса при выполнении задач, событий и переходов между ними. Проект не предназначен для создания или редактирования BPMN-моделей. Модель должна быть предварительно подготовлена во внешнем BPMN-редакторе и загружена в приложение в формате XML.

Возможности:
•	Загрузка готовой BPMN-модели из XML-файла
•	Обработка элементов BPMN 2.0
•	Отображение структуры бизнес-процесса
•	Запуск и остановка симуляции
•	Визуализация движения токенов по процессу
•	Отслеживание текущего состояния процесса
•	Обработка последовательности выполнения элементов модели
•	Поддержка ветвлений процесса

Общий сценарий работы:
1.	Пользователь подготавливает BPMN-модель во внешнем редакторе
2.	Пользователь экспортирует модель в формате XML
3.	XML-файл загружается в приложение
4.	Программа разбирает структуру модели
5.	На основе элементов и связей формируется представление процесса
6.	Пользователь запускает симуляцию
7.	Токены перемещаются по допустимым переходам процесса
8.	Приложение отображает текущее состояние выполнения модели

Поддерживаемые элементы:
•	Start Event
•	End Event
•	Intermediate Event
•	Simple Task
•	User Task
•	Service Task
•	Send Task
•	Receive Task
•	Manual Task
•	Business rule Task
•	Script Task
•	Call Activity
•	Exclusive Gateway
•	Parallel Gateway
•	Sequence Flow
•	Pools

Основные компоненты приложения:
•	Модуль загрузки – открывает BPMN XML-файл
•	Модуль разбора XML – извлекает элементы и связи модели
•	Модель процесса – представляет  события, задачи, шлюзы и переходы
•	Модуль симуляции – управляет состоянием процесса и движением токенов
•	Модуль визуализации – отображает модель и текущее положение токенов
•	Модуль обработки ошибок – сообщает о некорректном файле или неподдерживаемых элементах

 Возможные улучшения (ограничения текущей версии):
•	Улучшение визуализации состояния элементов
•	Поддержка дополнительных элементов BPMN 2.0
•	Расширение перечня поддерживаемых нотаций
•	Редактирование моделей
•	Поддержка таймеров
•	Сохранение результатов симуляции
